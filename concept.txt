WHEN TO USE __name__

__name__ is a special built-in module variable automatically created by Python. It stores the name of the current module. When a file is run directly, its value is "__main__". When imported, its value is the module's name. This behavior is used with if __name__ == "__main__": to control execution.

HOW? 

Use if __name__ == "__main__": when a Python file contains execution code that should run only when the file is executed directly.
Examples:
Calling functions
Creating objects and using them
Running tests
Printing output
Starting the main program flow
If a file only contains definitions (classes, functions, constants, reusable logic) and no code that needs to execute immediately, then if __name__ == "__main__": is usually unnecessary.
